# 🧮 Nova Calculator

A modern, responsive scientific calculator built with **React.js** and **CSS**, featuring a sleek black and blue theme.

🌐 **Live Demo:** https://calculatorapp-iota-ebon.vercel.app/

✨ Features
- Basic arithmetic operations
- Scientific functions: sin, cos, tan, log, ln, and more
- Square roots, powers, factorials, and constants
- Degree and radian modes
- Keyboard support
- Responsive design for mobile and desktop

🛠️ Tech Stack
- React.js
- JavaScript
- CSS
- Vite

🚀 Run Locally
```bash
git clone <your-repository-url>
cd calculatorapp
npm install
npm run dev
```
